# AI Interview Prep

A full-stack AI-powered interview preparation platform built to help candidates practice interview questions, structure answers, and prepare systematically across technical and behavioral topics.

## Tech Stack

- **Frontend:** React, Vite, Sass (SCSS)
- **Backend:** Node.js, Express, MongoDB Atlas
- **AI Integration:** Google Gemini API
